# 玻璃自动门 · 1.8.5

入口为双扇玻璃门，向左右滑动，打开后停在两侧固定玻璃后方。门框、磨砂防撞条和雨天水珠都随活动门扇移动；1.8.5 删除固定的竖向白色反光线，玻璃仍按场景光照显示。

## 使用

- **漫游**：从门外或门内靠近入口，玻璃门自动打开，无需按键或点击。入口感应以玩家位置为准，不要求朝向门口；二楼不会触发。
- **主菜单**：把鼠标移到画面中的入口附近即可打开。鼠标保持在入口时，门会持续打开；环看和缩放后仍按当前镜头识别入口，操作侧栏不会触发门口感应。
- **关闭**：玩家或鼠标离开后延迟约 1.1 秒关门。关门过程中重新靠近会立即反向打开，门扇平滑移动，不瞬移。暂停漫游时，站在入口的玩家仍保持开门；阅读弹窗打开时场景继续暂停。

门扇碰撞与滑动位置同步：关闭时不能穿过玻璃，打开后可从入口正常通行。手机漫游同样通过玩家接近触发；主菜单鼠标感应供鼠标操作使用。
