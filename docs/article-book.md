# 文章翻页阅读（1.8.0）

从实体书架或馆藏目录取下文章，默认以书本打开。封面只使用纯色背景和文章标题，打开后自动分页成双页正文。点击、拖动纸页或使用左右方向键翻阅；封面居中，展开后的双页整本居中。

右上角「Aa」切换字号并重新分页；页码保存在当前浏览器。屏幕宽度或字号变化后，按原阅读进度换算页码。文章正文仍取决于博客 RSS：摘要订阅只能显示摘要，不会自动获取订阅以外的全文。

工具栏「连续阅读」切换回原有网页正文，适合点击链接、复制代码、查看复杂表格和嵌入内容。翻页模式保留文字、标题、引用、列表、图片与代码文本；表格按行呈现为文本。两种模式分别保存阅读页码与滚动位置，阅读方式也会记住。

图片按翻页附近加载，读取超时不会阻止继续翻阅；Canvas 2D 不可用时自动切回连续阅读。翻页不创建新的 WebGL 上下文，书店 3D 无法显示时仍能从馆藏目录阅读。

漫游期间，点击「放回书架」或按 Esc 关闭阅读后恢复漫游。手机与桌面沿用原有操作方式。
