# 配色与歌单显示

在独立书店后台的「界面高亮配色」选择晴空蓝、湖水绿、雾紫、樱花粉或暖金，也可使用颜色选择器或填写六位 HEX 颜色。点击「保存设置」，刷新书店后生效。高亮颜色作用于按钮、天气选择、滑块和阅读链接，按钮文字自动适应颜色深浅。

「音乐来源与歌单」中，每个歌单都有「在前端显示此歌单」开关。关闭后仍可编辑或重新启用，访客页面与公开音乐接口均不再提供该歌单。关闭默认歌单时，默认选择自动回到「书店原创」；其他启用歌单不受影响。旧配置没有开关字段时按启用处理。

纯静态网站可在 config.json 设置：

```json
{
  "uiAccent": "#83baff",
  "musicPlaylists": [
    {
      "id": "qq-reading",
      "name": "我的 QQ 歌单",
      "enabled": false,
      "type": "meting",
      "url": "https://你的接口.example/meting/",
      "server": "tencent",
      "playlistId": "123456789"
    }
  ]
}
```

已有后台设置优先于 config.json 预设。升级时保留 .bookstore，进入后台选择配色和歌单开关后保存即可。

一楼桌子四周的书使用倾斜展示支架，带圆角加重底座、金属背撑、软垫与前挡边。RSS 阅读书与装饰书保持相同展示方式；中央保留两层、南北两面隔断的书架。
