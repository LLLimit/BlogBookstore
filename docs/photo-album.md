# 旅游册 · TRAVEL NOTES · 1.8.2

在导航点击「旅游册」，或漫游时拿起一楼阅读桌上的旅游册。阅读界面为白色，标题是 **Places worth keeping.**。封面使用后台选择的照片和白色 **TRAVEL NOTES** 字体；没有选择时用排序后的第一张照片。合上的封面居中，打开时向右平滑展开，完整双页书保持居中。

翻页使用连续弯曲纸面、双面图像和移动阴影，不依赖第二个 WebGL 场景，避免旧版渲染降级后只剩静态换图。支持按钮、方向键、点击和拖动；关闭或 Esc 从漫游中直接恢复漫游。末页为白纸，显示 **STRAIGHT AWAY......** 和 **THERE ARE STILL MANY JOURNEYS AHEAD IN MY LIFE...... WAITING TO BE EXPLORED**。继续翻页时只能拉到约一半，并回弹到末页。

展示哪些旅游册只在后台设置。前台没有配置或同步按钮；单本直接翻阅，多本显示照片封面目录。后台入口不在前台导航中展示，在书店网址后添加 `/admin` 即可进入。

## 后台编辑：封面、章节、排序与版式

在「展示的旅游册」完成同步后，点击 **编辑旅游册**。每本独立保存：

1. **封面**：从已同步照片中选择，也可在照片卡片点击「设为封面」。
2. **章节**：填写章节顺序，每行一个，例如 `HONG KONG`、`TOKYO`。勾选照片后批量归入章节，或逐张填写所属章节；前台会显示章节扉页与导航。
3. **照片排序**：在「选择章节 / 章内排序」中选择章节，只列出这一章的照片，使用 ↑ ↓ 或输入章内序号调整。其他章节的相对顺序与位置保持；「全部照片」视图调整全局排序。章节提前 / 后移按钮移动整个章节，未分类在前台最后展示。也可以点击「按章节整理单页配对」，把每个章节的单页照片集中在一起，再接跨页照片。调整后点击「保存这本旅游册」。
4. **显示版式**：自动、铺满整本双页、双页留白、铺满单页、单页留白。可逐张选择，也可勾选多张批量应用。自动模式中，宽高比至少 1.6 的横幅默认铺满双页；其余留白展示。铺满会按比例居中裁切，留白则保留完整构图。

相同章节内的单页照片按排序两两配对。切换到跨页或章节时，未配对的单页旁用章节索引补齐，避免无信息的空白页；一键配对可以减少这些索引页。章节及照片顺序均由后台决定，日常更新的新照片追加到现有排序后。

## 页角文字、日期与书外故事

每张照片可填写日期时间、页角文案与故事，选择日期 / 文案的左下、右下或自动外侧位置。跨页照片还能分别填写左页左下与右页右下文案；填入其中任一项时使用这两项替代通用页角文案，日期仍按选择的位置显示。纸页不再固定印刷相册名称。故事最多 2000 字，支持换行，可放在书外左侧、右侧或按所在页自动分配；手机窄屏会放到书下方，保证可读。

日期按填写的当地时间展示，不转换时区。留空后保存可清除对应文字。元数据独立保存在 `.bookstore`，每日同步不会覆盖；升级保留此前的日期和故事。切换照片组前的未保存输入会暂存于当前编辑界面，最后点击「保存这本旅游册」统一写入服务器。

1.8.1 起，页面底部「保存设置」也会先保存已打开的旅游册，再保存网站设置，完成后停留在当前页面。失败时输入仍在页面中，可以重试；不要直接刷新丢失未保存内容。连接中断可按 [后台保存排查](admin-save.md)检查日志与代理线路。

## 配置与指定相册

1. 在书店网址后添加 `/admin`，登录后台 →「展示的旅游册」。
2. 来源选择「Smart-Gallery 相册页面」，填入包含 `[gallery]` 的博客公开相册页面地址。例如：`https://blog.darkduck.fun/index.php/pictures.html`。
3. 点击「读取可选相册」，勾选旅游、生活等需要展示的相册。也可以直接填写相册编号或完整名称，多个用逗号隔开。留空展示全部公开相册。
4. 保存设置，再点击「立即检查并下载更新」。完成后刷新书店。

页面模式无需修改博客插件，识别公开相册节点，读取 Smart-Gallery 图片接口，保留相册顺序、照片顺序和说明，跳过视频、密码相册。页面模式最多 12 本画册；JSON 模式最多 60 本；每本最多 300 张，合计最多 800 张。Smart-Gallery 页面结构变化后可能需要更新适配。

## 本地缓存与提前加载

独立 PHP 版将照片下载到书店数据目录下的 `gallery-images/`，默认位于 `.bookstore/gallery-images/`。首次导入和每天检查均分批进行，保存下载进度；失败时保留已下载图片，后台显示具体失败项，手动检查可重试。

- 原图保留，单张最多 12 MB、4000 万像素，支持 JPEG、PNG、GIF、WebP、AVIF。
- 后台编辑只请求最长边 400px、质量 72 的小缩略图，不把原图缩小显示后继续传输原图。旧缓存通过「生成 / 补齐缩略图与无损 WebP」分批补齐；打开编辑界面也会续做未完成任务，图片陆续出现，当前编辑输入保持。
- 前台纸页保持原尺寸：提前生成无损 WebP，只有更小的文件才替代原图。不会使用旧版 1600px 有损预览；不会为了速度降低照片分辨率或采用有损重编码。原图始终保留。照片已经是高效的 JPEG / WebP / AVIF 或转换后更大时，继续使用原文件，不能保证所有照片都大幅变小。
- 浏览器从书店自己的图片接口加载。图片文件名由内容哈希生成，支持长期缓存；来源变化后使用新地址。
- 网站空闲时预载第一本封面；打开或翻页的可见照片使用高加载优先级，必要时中断不相关的后台预载，随后续传。只预载接下来一组书页，后台最多一个图片请求，不再整本原图抢带宽。解码缓存按照片像素数和张数限制，保留完整图片清晰度。
- 后台可设置本地存储限额，默认 512 MB，原图和展示图都计入。达到上限时停止新增下载并提示。

服务器需启用 PHP cURL、DOM/XML，并允许网站运行用户写入数据目录。图片生成优先使用 **Imagick**，限制内存 / 映射缓存各 32 MB，磁盘缓存 256 MB，单线程；未启用时使用 GD。GD 无损 WebP 常量需要 PHP 8.1 或以上；PHP 7.4 + GD 仍能生成缩略图，前台保留原图，PHP 7.4 + Imagick 可生成无损副本。GD 对不支持的色彩配置或不能安全读取方向的照片保留原文件，内存不足时提示并跳过；不自动提高 PHP 内存上限。开启扩展或调整资源后再次点击生成按钮可重试。继续保留 `.bookstore` 直接访问拦截，图片通过 `api/gallery-image.php` 提供，图片 GET 不转码。

每日 `gallery-cron.php` 会在同步后生成新增照片的缩略图与无损副本；只生成现有照片、不访问博客来源时可运行（替换 PHP 和网站路径）：

```sh
/www/server/php/74/bin/php /www/wwwroot/book.example.com/api/gallery-optimize.php
```

生成任务单次最多运行约 4 分钟，未完成继续运行即可；启用扩展后加 `--retry` 重新尝试以前跳过的照片。推荐每 5 分钟执行一次已有 `gallery-cron.php` 任务，它仍只每 24 小时检查相册源。生成过程中继续读原图，完成后刷新前台使用新的无损文件；章节、故事和排序不会改变。

后台「查看同步状态」会显示下载失败的具体原因：DNS、连接、下载超时、HTTPS CA 证书或 HTTP 状态。修复服务器连接问题后点击「立即检查并下载更新」重试。浏览器的接口连接失败会单独提示，不等同于博客相册不存在。旧版个人包附带的预置照片仅用于恢复同一来源的失败空缓存，已有非空缓存不会被替换；1.8.0 个人包沿用服务器缓存，不附带旧版照片快照。

后台的 Content-Security-Policy 必须包含 `connect-src 'self'`，才能调用本站相册接口；服务器额外添加 CSP 时也需要允许同站连接。旧版后台遗漏了这一项，会在浏览器中直接报 `Failed to fetch`。

1.7.3 支持 `local/照片/文件名.jpg` 等中文目录和含空格的文件名：读取相册时先按路径段进行网址编码，再验证和下载。已经编码的路径不会重复编码，外链图片的查询参数保留；单张异常路径不会中断其他照片。如果整本相册的图片路径都无效，会明确报错。中文目录不需要重命名。

1.7.2 已将图片下载错误处理改为 PHP 7.4 兼容写法。如果接口返回 HTTP 200 但响应是 HTML，先检查 PHP 错误日志；旧补丁中的 PHP 8 `match` 语法可能导致这一情况。覆盖完整 1.7.2 程序后，若 OPcache 仍返回旧语法错误，重启对应 PHP 服务。

## 每天自动检查与手动检查

访客打开网站时，如果距离上次检查已满 24 小时，就在后台补做检查、分批下载；24 小时内复用本地照片。失败的来源也遵守检查间隔。后台按钮可立即检查，不必等待一天。

无人访问时也需要更新，请在宝塔「计划任务」等服务器调度器中添加 Shell 任务，使用服务器实际 PHP 命令与网站根目录：

```sh
/www/server/php/84/bin/php /www/wwwroot/book.example.com/api/gallery-cron.php
```

只需每天运行即可检查更新。相册很多时建议每 5 分钟运行：脚本每次最多工作约 4 分钟，继续未完成队列，但同一个来源和相册选择仍每 24 小时检查一次。更换 PHP 版本时同步修改命令。CLI 脚本无法通过网页触发强制检查。

`--force` 可用于服务器上的手动立即检查：

```sh
/www/server/php/84/bin/php /www/wwwroot/book.example.com/api/gallery-cron.php --force
```

若通过 `BOOKSTORE_DATA_DIR` 自定义数据目录，计划任务也要使用相同环境变量。脚本运行成功退出码为 0；未完成或失败为 1；已有任务同步中为 2。

## 可选的 Typecho 桥接插件

将 `BookstoreGallery` 文件夹放到 `usr/plugins/BookstoreGallery/`，后台启用 **BookstoreGallery**。插件文件夹、显示名和命名空间同名。进入插件设置复制接口地址，独立书店来源选择「BookstoreGallery 接口 / JSON 画册」。

接口示例：`https://example.com/index.php/action/bookstore-gallery`。

桥接插件只查询 SmartGallery 数据库的无密码相册，不修改原插件、图片或数据库。独立书店负责每日同步和本地下载。

## 图片在哪里

[Smart-Gallery](https://github.com/3554171776/Smart-Gallery) 上传目录为 `usr/uploads/SmartGallery/YYYY/MM/`；文件名可能为 `q80_时间戳.webp` 或 `raw_时间戳.jpg`。数据库表（加 Typecho 表前缀）是 `smart_gallery_albums`、`smart_gallery_images`，`filename` 可能是相对上传路径或外部 HTTP(S) 地址。本项目按相册读取，以保留分组、顺序和说明。

## 通用 JSON 与静态部署

其他博客或相册系统可以提供以下格式，来源选择 JSON：

```json
{"albums":[{"id":"travel","title":"旅行手记","description":"值得留住的地方","photos":[{"url":"https://example.com/01.jpg","caption":"某个雨天的街角"},{"url":"https://example.com/02.jpg","caption":"傍晚"}]}]}
```

纯静态部署或 Typecho 书店插件模式：在配置中填写 `galleryUrl`（JSON 地址）、`galleryAlbums`（ID 或名称数组，留空为全部）。此模式直接从图片来源加载，需要允许跨域；每日下载、服务器缓存及独立后台功能属于独立 PHP 版。

## 升级

先备份网站，将升级包 `BlogBookstore/` 内的文件覆盖网站根目录，保留 `.bookstore`（后台密码、设置和本地图片）、自定义图片及音乐。已有后台设置优先于 `config.json`，升级后请保存相册地址和所选相册。服务器上的计划任务需要自行添加。

个人升级包可预置已经下载的公开画册，首次读取时导入本地缓存，来源与选择必须匹配；通用源码不携带个人照片或音乐。旧元数据和浏览器缓存的照片可能保留到下一次成功同步或缓存到期，需要撤回已公开图片时也应处理书店本地副本。

3D 书店场景无法显示时，旅游册仍可用 Canvas 2D 翻页。旅游册不额外占用 WebGL 上下文；极少数没有 Canvas 2D 的环境使用带翻页过渡的普通图片视图。
